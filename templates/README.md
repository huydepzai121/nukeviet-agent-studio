# Skeleton module

Hai cây thư mục mẫu. Thay `__MODULE__` (snake), `__MODULE_UPPER__` (hằng), `__TITLE__`, `__AUTHOR__` trước khi copy vào site.

- `module-5x/` copy vào gốc mã NukeViet 5 (bên trong đã có `src/`).
- `module-4x/` copy vào gốc site NukeViet 4 (không có `src/`).

4.x giữ PHP 7.4: không `match`, không union type, template XTemplate, ngôn ngữ tách `admin_vi.php`, block `.ini` dạng XML.

5.x dùng `NVSmarty`, `$nv_Lang`, một `language/vi.php`, block `.json`.
