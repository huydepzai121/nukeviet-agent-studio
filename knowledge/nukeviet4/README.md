# Gói kiến thức NukeViet 4.x

Tóm tắt convention để agent viết module NukeViet 4, dựa trên [wiki NukeViet](https://wiki.nukeviet.vn/) (programming4). Đây là tài liệu viết cho studio, không phải bản sao wiki.

Dùng gói này khi dự án chọn **4.x**. Không áp dụng `$nv_Lang`, Smarty, hay thư mục `src/` của NukeViet 5.

Đọc tiếp:

- `differences.md` — khác 5.x
- `module.md` — khung module
- `template.md` — XTemplate
- `language.md` — `$lang_module`, `admin_vi.php`
- `block.md` — file `.ini` (nội dung XML)
- `security.md` — input, SQL, CSRF kiểu 4.x
- `coding-standard.md` — PHP 7.4, PSR-2
